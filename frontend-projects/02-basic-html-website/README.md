# 🌐 Basic HTML Website

My second frontend project from [roadmap.sh](https://roadmap.sh): a simple multi-page website built with **only HTML**. No CSS, no JavaScript, just structure! 🧱

🔗 **Project page on roadmap.sh:** https://roadmap.sh/projects/basic-html-website

📂 **Project repository:** https://github.com/danilopillitu/roadmap-sh-projects/tree/main/frontend-projects/02-basic-html-website

## 🤔 What is this?

A small personal portfolio website for a made-up person, **Mario Rossi**, frontend developer. All the content is fake (hello, Lorem ipsum! 😄) and only used to practice.

The website has 4 pages, all connected by a navigation bar:

- 🏠 **Home**: introduction, links to the projects, LinkedIn and GitHub, education and reviews
- 💻 **Projects**: a list of 4 projects, with links from the homepage
- 📝 **Articles**: 3 articles with a short description
- 📬 **Contact**: a form (name, surname, email, phone, message) and address information

## 🚀 How to run the project

No installation needed, just a browser! 🌍

1. Clone the repository:
   ```bash
   git clone https://github.com/danilopillitu/roadmap-sh-projects.git
   ```
2. Go into the project folder:
   ```bash
   cd roadmap-sh-projects/frontend-projects/02-basic-html-website
   ```
3. Open `index.html` in your browser (double-click it or drag it into a browser window) ✨
4. Use the navigation bar to visit the other pages 🧭

## 📚 What I learned

- 📄 How to create a website with multiple pages
- 🧭 How to build a navigation bar that links all the pages
- 🏷️ How to use semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`)
- 🔍 How to add SEO and Open Graph meta tags to every page
- 📝 How to create a form with `label`, `input` and `textarea`
- ⚓ How to link to a specific part of a page using an `id` (like `projects.html#project-01`)
